PROYECTOS

Asistente web integrado con Jira | ESCOM-IPN | 2024

Cesar desarrolló principalmente en Python un sistema cuyo objetivo era automatizar parte de la gestión de tareas durante reuniones.
El sistema grababa el audio de la reunión, realizaba la transcripción y procesaba el texto para identificar instrucciones, personas y tareas asignadas, también podía reconocer cuando una persona indicaba que había terminado una tarea y utilizar esa información para actualizar su estado en Jira.
Utilizó JSON para estructurar parte de la información extraída de la transcripción, integró la API de OpenAI para apoyar la interpretación del lenguaje y la API de Jira para crear o actualizar las tareas correspondientes.
Por ejemplo, si durante una reunión se asignaba una actividad a una persona, el sistema procesaba la transcripción, obtenía los datos relevantes de forma estructurada y los enviaba a Jira.
Para mejorar el reconocimiento de voz, el equipo trabajó con datos de distintas voces, incluyendo voces de hombres y mujeres con diferentes características de frecuencia. 
Uno de los retos principales fue interpretar correctamente lo que se decía durante la reunión y transformar esa información en acciones útiles dentro de Jira.
Tecnologías utilizadas: Python, reconocimiento de voz, JSON, API de OpenAI, API de Jira, JavaScript, HTML, CSS, Git y GitHub.

Asistente con LLM para análisis de documentos | ESCOM-IPN | 2024

Tecnologías y áreas de trabajo: Python, modelos de lenguaje y procesamiento de documentos.

Reconocimiento de voz en tiempo real | ESCOM-IPN | 2024

Cesar desarrolló una aplicación de transcripción en tiempo real que fue desplegada en una máquina virtual. Trabajó en la configuración del entorno, el procesamiento de audio y la validación técnica del funcionamiento del sistema.
